# Conversation Snapshot

**다음 사람이 바로 이어서 작업할 수 있도록 현재 상태와 다음 행동부터 정리한다.**

- 현재 상태: 목표와 범위, 완료·진행 중인 작업, 검증 결과와 미확인 사항
- 다음 행동: 바로 실행할 작업, 의존성·차단 요소와 필요한 사용자 입력
- 결정과 제약: 채택한 방향·이유, 사용자 수정·승인 범위, 재논의를 막는 중요한 폐기 사유
- 근거와 작업 위치: 관련 파일·링크·명령 결과, 이어서 작업할 브랜치·워크트리·실행 중 서비스

- 작업에 필요한 항목만 포함하고 빈 섹션·반복 설명을 만들지 않는다. 빠진 정보가 재개에 필요하면 미확인으로 표시한다.
- 확인된 사실·추론·미검증 상태를 구분하고 대화에 없는 내용을 만들지 않는다.
- 기본은 응답에 Markdown을 출력하며 파일 저장은 요청된 경우에만 수행한다. 전체 논의 기록을 요청하면 주요 논의 흐름·후보 아이디어·미해결 질문을 추가한다.
