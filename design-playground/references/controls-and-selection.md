# 조정과 선택본

**화면의 표현·저장·인계가 동일한 상태를 사용하도록 만든다.**

## 컨트롤 설계

- 목록은 행 높이·열 너비·보조 정보 노출, 상세 화면은 본문 폭·이미지 비중·섹션 간격처럼 판단이 필요한 축을 고른다. 공통 스타일은 타이포·색상·테두리·radius 중 필요한 것만 노출한다. 동작이 핵심이면 전환 시간·펼침 방식도 포함한다.
- 연속값은 슬라이더와 숫자 입력, 제한된 선택은 토글·선택 메뉴, 여러 값의 조합은 프리셋 등으로 제공한다. 프리셋이 바꾸는 실제 값과 범위도 확인할 수 있게 한다. 사용자 지정 범위와 기존 토큰을 우선하고 부적절한 값은 이유를 보여준다.
- 컨트롤은 실제 렌더링 상태·CSS 변수·컴포넌트 속성에 연결한다. 저장용 숫자와 화면용 하드코딩 값을 따로 유지하지 않는다. 전역 규칙과 특정 영역의 예외를 구분한다.
- 기준안은 변경하지 않는 스냅샷으로 보존하고 현재안을 독립적으로 조정한다. 초기화와 불러오기가 무엇을 바꾸는지 표시하고 기준안 비교 중 현재 선택값을 잃지 않게 한다.

## 구조 수정

배치·표현 형식·콘텐츠 노출 변경도 선택본에 포함한다. 지원하는 구조 선택은 식별 가능한 값으로 저장하고, 대화로 코드를 수정한 경우 수정된 실행 원본을 함께 보존한다. 원본 개정 식별자를 선택본과 맞춰 서로 다른 버전의 조합을 피한다. 수정 때문에 사용할 수 없어진 값은 조용히 버리지 말고 대체·제외 이유를 전달한다.

## 저장과 재적용

- 새로고침 복원을 위한 로컬 저장과 이동·인계를 위한 파일 내보내기·불러오기를 제공한다. 로컬 저장만으로 인계를 완료했다고 하지 않는다. 저장이 제한된 환경에서는 제한을 표시하고 파일 저장·불러오기로 이어간다.
- 예를 들어 JSON 선택본에 형식 버전, 화면/원본 개정 식별자, 현재 또는 사용자 확정 여부, 규칙별 값·단위·적용 범위, 구조 선택, 비교 상태·viewport를 기록한다. 파일명이나 스키마를 모든 작업에 고정할 필요는 없다.
- 내보내기는 화면에 적용된 전체 유효값을 저장한다. 변경분만 저장하려면 동일한 기준 원본을 함께 제공한다. 읽을 수 있는 결정 메모와 실행값이 다르면 실제 상태를 확인해 일치시킨다.
- 불러올 때 형식·대상·버전·지원하는 값과 범위를 확인한다. 호환되지 않는 파일을 부분 적용하고 성공으로 표시하지 않는다. 실패 시 기존 선택을 유지하며 원인을 알린다.
- 내보낸 선택본을 다시 불러와 값과 화면이 복원되는지 확인한다. 임시로 다르게 조정한 뒤 복원해 저장 버튼 존재만으로 검증을 대신하지 않는다.

## 구현 전달

원본 실행 방법, 선택본과 원본의 대응, 레퍼런스에서 채택한 특징, 구조 변경, 공식 토큰과의 대응·차이, 시안 전용 요소, mock·미확정 정책을 필요한 만큼 묶는다. 사용자가 확정하지 않았다면 현재 탐색값으로 명시한다. 구현 요청에는 선택값을 적용하되 기존 공식 토큰 변경은 해당 요청 범위에 맞게 처리한다.
