# 상태와 모션 재생

로딩, 펼침, 내용 교체처럼 시간 순서가 판단에 필요한 비교 시안에 적용한다. 타이밍 편집과 선택값 저장이 목적이면 design-playground를 사용한다.

- 결과 시나리오와 시간상의 시점을 독립적으로 선택한다. 예를 들어 결과는 정상·빈 결과·실패 중 요청에 필요한 것만 고르고, 시점은 시작·대기·전환·완료 중 실제로 구분되는 것만 제공한다. 초기 화면과 전후 패널의 설명에서 실측 데이터와 모의 응답 시간을 구분한다.
- 양쪽에 같은 시나리오와 타임라인을 적용한다. 시점을 직접 고르면 해당 프레임에서 멈추고, 재생 버튼은 두 패널을 시작 상태로 되돌린 후 동시에 재생한다. 기본 배속은 1×로 두고 0.5×와 2×를 제공한다. 모의 응답 지연과 CSS 전환·페이드 시간을 같은 비율로 조절한다.
- 재생을 다시 시작하거나 시나리오·시점을 바꾸면 이전 예약을 취소한다. 배속 변경은 다음 재생에 적용하거나 처음부터 같은 배속으로 재시작한다. 동작 줄이기 설정에서는 이동·크기 변화와 반복 모션을 끈 상태에서도 결과를 비교할 수 있게 한다.
- 재생 제어와 표시용 번호는 제품 UI 밖에 둔다. 대표 시점을 정지한 Before·After PNG와 오프라인으로 열리는 HTML을 함께 제공한다. PNG에는 시간 흐름을 판단할 수 있는 대기·전환·결과 중 필요한 프레임을 담는다.
- 실제 브라우저에서 두 패널의 동기화, 느리게·빠르게 재생, 재생 중 상태 전환, 동작 줄이기 설정을 확인한다. CSS 모션을 검사할 때는 정지 프레임 외에도 재생 도중의 높이 또는 투명도가 시작값과 끝값 사이에 있는지 확인한다. agent-browser를 사용할 수 없으면 설치된 Playwright Chromium으로 같은 검사를 수행하고 사용한 도구를 밝힌다.
