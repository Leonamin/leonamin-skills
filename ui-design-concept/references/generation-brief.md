# 이미지 생성 브리프

현재 도구가 이해할 수 있는 프롬프트로 아래 내용을 압축한다. 특정 모델·API나 출력 해상도 지원을 가정하지 않는다.

- 대상: 제품, 화면, 사용자, 주요 목표
- 조건: 언어, 목표 화면 크기·비율, 표시할 상태와 데이터
- 고정: 브랜드·탐색·필수 정보·사용자 행동·확인된 업무 정책
- 탐색: 배치, 정보 강조, 이미지 활용 등 바꿀 수 있는 부분
- 근거: 실제로 첨부한 화면 이미지와 텍스트로 추출한 토큰·컴포넌트 제약
- 표현: 현실적인 UI 위계·타이포·여백; 설명 문구와 UI 콘텐츠 분리
- 제외: 확인되지 않은 기능·수치·정보를 빈 공간 채우기용으로 추가하지 않기

실제 데이터를 제공받았다면 의미와 날짜·금액을 보존한다. 예시 데이터가 필요하면 일관된 값을 쓰고 시안용임을 인계에 표시한다. 민감한 실제 데이터는 참고 목적에 필요한 범위로 제한하고 필요하면 가린 자료를 사용한다.

전체 화면 UI를 기본으로 하고 장식용 기기 프레임·원근·그림자는 요청이나 참고 방향에 필요한 경우에만 사용한다. 읽기 어려운 작은 화면을 한 이미지에 무리하게 모으지 않는다. 정확한 문구가 깨졌다면 재생성·편집으로 수정하고, 남은 오류는 정정 문구를 인계한다.

## 상태 확장 프롬프트

대표 이미지를 실제 참조로 전달하고 다음 차이만 지정한다.

- 기준: 선택한 방향의 이미지 식별자
- 유지: 헤더·탐색·타이포·색·간격·공통 요소
- 변경: 상태의 노출 조건, 대체할 영역, 보일 문구와 가능한 행동
- 일관성: 정상 콘텐츠가 남아야 하는 부분과 사라져야 하는 부분

도구가 이미지 참조를 지원하지 않으면 그 한계를 밝히고 텍스트 제약을 재사용한다. 결과의 일관성은 직접 확인하며, 원본 이미지를 첨부한 것처럼 표현하지 않는다.
