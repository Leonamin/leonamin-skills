# 이미지 생성 브리프

**확인된 제품 정보와 탐색할 디자인을 구분해 현재 도구의 프롬프트로 전달한다.**

- 대상: 제품·화면·사용자·주요 목표
- 조건: 언어·화면 크기·비율·상태·데이터
- 고정: 브랜드·탐색·필수 정보·행동·확인된 정책
- 탐색: 배치·강조·이미지 비중 등 바꿀 부분
- 근거: 실제 첨부 이미지와 코드·문서에서 추출한 토큰·컴포넌트 제약
- 표현: 읽을 수 있는 위계·타이포·여백; UI와 설명 문구 분리
- 제외: 확인되지 않은 기능·수치와 빈 공간을 채우는 반복 소개문

제공 데이터의 의미·날짜·금액을 보존한다. 예시 데이터는 일관되게 사용하고 시안용임을 인계한다. 민감한 정보는 필요한 범위만 전달하거나 가린다.

도구의 모델·API·해상도 지원을 가정하지 않는다. 전체 화면 UI를 기본으로 하고 장식용 기기 프레임·원근·그림자는 요청이나 참고 방향에 필요할 때만 사용한다. 작은 화면을 한 이미지에 무리하게 모으지 않는다. 깨진 문구는 편집·재생성하고 남은 오류는 정정 문구와 함께 인계한다.

## 상태 확장

대표 이미지를 실제로 참조하며 `기준 이미지 / 유지할 공통 요소 / 노출 조건 / 변경 영역·문구·행동 / 남거나 사라질 콘텐츠`를 지정한다.

이미지 참조를 지원하지 않으면 한계를 밝히고 텍스트 제약을 재사용한다. 결과의 일관성은 직접 확인하고 원본을 첨부했다고 주장하지 않는다.
