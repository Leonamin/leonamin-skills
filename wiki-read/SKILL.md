# 위키 읽기

**관련 지식만 읽고 현재 작업에 미치는 영향과 근거를 먼저 전달한다. 위키와 설정은 수정하지 않는다.**

## 경로와 탐색

1. 프로젝트 루트를 확인하고 요청에서 지정한 경로 → `.agents/wiki-path` → `.env`의 `WIKI_PATH` → 세션에서 확인한 경로 순으로 찾는다. 상대 경로는 프로젝트 루트 기준이다.
2. 경로가 없거나 초기화되지 않았으면 설정을 추측하거나 파일을 만들지 않고 `$wiki-setup`을 안내한다.
3. 프로젝트의 `.agents/wiki-structure.md`와 위키 루트 `index.md`를 읽고, 제목·설명·태그·링크로 관련 문서를 고른다.
4. 선택한 최상위·하위 디렉토리의 `index.md`를 먼저 읽고 개별 문서로 이동한다. 모든 문서를 일괄 읽지 않는다.
5. 시간 흐름·결정 변경이 중요하면 `logs/index.md`와 관련 로그를 읽는다. 마이그레이션 중인 위키의 루트 `log.md`는 이전 기록으로 구분한다.

## 해석과 보고

- Decision은 현재 상태와 Status를 확인하고 Superseded 결정을 현재 규칙으로 적용하지 않는다.
- Concept에서는 정의·전제·시스템 관계·제약을, Reference에서는 외부 출처와 적용 범위를 추출한다.
- 로그는 변경 시점과 문서 흐름의 보조 근거로 사용하며 관련 항목만 읽는다.
- 문서 충돌은 임의로 해소하지 않고 충돌과 판단에 필요한 정보를 보고한다. 오래된 내용은 필요하면 현재 코드·설정·테스트와 대조하고 확인 여부를 밝힌다.
- 위키의 사실·결정과 코드 등 다른 근거·추론을 구분한다. 위키에 없는 내용은 “위키에 기록되지 않음”으로 표시하고 결정을 지어내지 않는다.
- 답변은 현재 작업에 대한 영향부터 쓰고, 필요한 사실·제약·기존 결정·충돌·추가 확인 사항과 문서 제목·파일 링크를 포함한다. 단순 질문은 짧게 답하며 원문을 길게 복사하지 않는다.
- 새 문서·index·로그·디렉토리를 만들거나 위키·`.agents/wiki-path`·`.agents/wiki-structure.md`를 수정하지 않는다.
