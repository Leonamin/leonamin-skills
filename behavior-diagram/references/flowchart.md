# 흐름도

- 시작 → 작업 → 판단 → 종료 순서로 읽히게 배치한다. 작업에는 동작을 적고, 판단에는 `권한이 있는가?`처럼 경로를 가르는 질문을 적는다.
- 판단 도형에서 나가는 화살표에 `허용` / `거부`처럼 실제 조건을 붙인다. 기본 경로가 있으면 표시한다. 재시도는 돌아가는 단계와 반복을 끝내는 조건이 보이게 그린다.
- Mermaid `flowchart TD`를 기본으로 사용하고, 넓은 화면에서 가로 진행이 더 읽기 쉬우면 `LR`을 사용한다. 판단은 마름모로 표현한다. 주 경로를 한 방향으로 두고 예외 경로는 분기한 판단 가까이에 둔다.
- 검증할 때 각 판단에서 조건별로 다음 목적지를 따라가고, 모든 경로가 의도된 결과나 반복으로 이어지는지 확인한다. 두 대안 경로가 같은 단계로 모이는 합류와 병렬 작업의 완료를 기다리는 합류를 구분한다.
