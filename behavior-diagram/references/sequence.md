# 시퀀스 다이어그램

- 한 시나리오의 시작 사건부터 결과까지 발신자, 수신자, 메시지를 순서대로 정리한다. 가로축은 참여자, 세로축은 사건 순서다. 같은 참여자는 같은 생명선에 둔다.
- 사람·화면·API·워커처럼 흐름을 이해하는 데 필요한 참여자를 배치한다. 메시지는 `예약 취소 요청`, `환불 결과 반환`처럼 무엇을 주고받는지 짧게 표시한다. 응답은 후속 동작이나 결과를 설명할 때 넣는다.
- Mermaid `sequenceDiagram`에서는 호출에 `->>`, 결과 응답에 `-->>`를 쓸 수 있다. 조건별 경로는 `alt` / `else`, 단일 선택 동작은 `opt`, 반복은 `loop`, 참여자 사이의 병렬 상호작용은 `par`로 표현한다. 큐에 넣는 시점과 워커가 소비하는 시점은 메시지 두 개로 그린다.
- 검증할 때 발신자와 수신자가 맞는지, 응답이 대응하는 요청 뒤에 있는지, 조건별 메시지가 해당 블록에 들어 있는지 확인한다. 비동기 동작은 실제로 기다리는 지점만 기다림으로 표현한다.
