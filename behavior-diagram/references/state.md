# 상태 전이 다이어그램

- 대상 하나의 생애주기를 정한다. 노드에는 `승인 대기`, `승인됨`, `반려됨`처럼 대상이 가질 수 있는 상태를 두고, 화살표에는 상태를 바꾸는 사건을 둔다.
- 같은 사건의 전이가 조건에 따라 달라지면 `사건 [조건]`으로 적는다. 전이하면서 일어나는 작업이 핵심이면 `사건 [조건] / 작업`으로 덧붙인다.
- Mermaid `stateDiagram-v2`에서는 시작을 `[*] --> Pending`, 전이를 `Pending --> Approved: 승인 [권한 있음]`처럼 표현한다. 종료가 있는 생애주기에는 `[*]`로 향하는 종료 전이를 쓴다.
- 검증할 때 각 화살표가 현재 상태에서 허용되는 사건인지 확인한다. 같은 상태에서 같은 사건이 여러 전이를 만들면 조건 또는 우선순위로 목적지를 결정할 수 있어야 한다. 실패·취소·재시도 뒤에 대상이 어느 상태에 머무는지도 확인한다.
