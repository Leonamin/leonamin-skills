# Figma 레이아웃과 검증

**구조적 관계는 오토 레이아웃으로 표현하고, 좌표 자체에 의미가 있는 영역만 자유 배치한다.**

## 기본 규칙

- Root Frame과 순서·정렬·간격·리사이징을 소유하는 작성 프레임에 오토 레이아웃을 적용한다. 페이지 캔버스에 Root Frame을 놓는 좌표는 허용한다.
- 일반 흐름의 자식은 `layoutPositioning = ABSOLUTE`로 두지 않는다. `x`·`y`는 자동 계산 결과에도 있으므로 속성의 존재만으로 실패 처리하지 않는다.
- 가로를 채우는 입력·주요 버튼·섹션은 부모에 추가한 뒤 `Fill container`, 내용 크기를 따르는 버튼·칩·레이블은 필요한 축에 `Hug contents`를 적용한다.
- 줄바꿈 텍스트에는 가로 크기 규칙과 콘텐츠에 따른 세로 크기를 설정하고 폭이 과도하게 줄지 않는지 확인한다.
- 간격은 `item spacing`, 안쪽 여백은 `padding`으로 표현하며 대응하는 spacing 변수가 있으면 연결한다. 일회성 색상·radius 대신 기존 토큰·스타일을 우선한다.
- 라이브러리 인스턴스 내부는 작성 프레임 검사에서 제외한다. 정책에 맞추려고 detach하지 않는다.

## 자유 배치 예외

오버레이·차트·지도·캔버스·시각 합성·불규칙 그리드처럼 위치 자체가 의미를 갖는 경우에만 허용한다.

1. 오토 레이아웃·wrap·grid로 의미와 리사이징을 보존할 수 있는지 먼저 확인한다.
2. 필요한 가장 작은 하위 프레임에 격리하고 `Layout Exception/<reason>`으로 이름 붙인다.
3. 예외 프레임은 상위의 정상 흐름에 참여시키며 절대 배치 자식은 그 안에만 둔다.
4. 고정·최소 크기·클리핑·크기별 동작을 명시하고 이유·영향 범위·검증 크기를 결과에 남긴다.

## Staggered Grid

- 네이티브 grid·wrap이 카드 순서와 리사이징을 보존하면 우선한다.
- 열 단위 읽기 순서가 허용되면 `Horizontal Auto Layout > Vertical Column Auto Layout > Card`로 구성하고 합의된 고정 폭 또는 Fill을 사용한다.
- 정확한 좌표·겹침·시각 순서가 필수면 `Layout Exception/Staggered Grid` 안에서만 자유 배치한다. 절대 자식이 자동 높이 계산에 포함되지 않으므로 프레임 높이와 크기별 동작을 지정한다.
- 콘텐츠 추가·삭제·번역·긴 텍스트에서 겹침과 잘림을 확인한다.

## 검증

- 작성 레이아웃 컨테이너의 `layoutMode = NONE`은 예외로 분류되지 않으면 실패다. Root 내부의 ABSOLUTE는 `Layout Exception/` 하위가 아니면 실패다.
- 역할에 맞는 Fill·Hug와 gap·padding 값/변수 연결을 확인한다.
- 전체 화면과 주요 섹션을 렌더링해 잘림·겹침·순서·빈 공간을 확인한다. 예외 프레임은 목표 크기와 콘텐츠 변화 조건에서 스크린샷으로 검증한다.
- 정상 컨테이너·의도된 예외·미분류 절대 배치를 구분해 보고한다.
